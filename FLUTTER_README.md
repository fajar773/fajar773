# Fajar773 Portfolio - Flutter Project

A Flutter application showcasing the portfolio and projects of Fajar Prasetyo Adi, a Mobile App Developer with expertise in Flutter and cross-platform app development.

## Getting Started

This project is a starting point for a Flutter application.

### Prerequisites

- Flutter SDK (>=3.0.0)
- Dart SDK
- Android Studio / VS Code with Flutter extensions

### Installation

1. Clone the repository:
```bash
git clone https://github.com/fajar773/fajar773.git
cd fajar773
```

2. Install dependencies:
```bash
flutter pub get
```

3. Run the app:
```bash
flutter run
```
